작업 표시줄에서 달리는 토끼가 PC 상태를 알려 주는 Windows 앱.

무료 다운로드 버전 고르기

Windows 10, 11 (64비트)

0.6% 평소 CPU 사용량 (코어 하나 기준)
60MB 메모리
3 기본 캐릭터: 토끼, 고양이, 말

분노 게이지

사용률이 오를수록 빨리 달리고, 모습도 바뀝니다.

  1. 0-59% 천사 파란 몸에 고리와 날개
  2. 60-89% 일반 노랗게 달아오름
  3. 90% 이상 악마 빨간 몸에 뿔과 꼬리

작업 표시줄에서 다 된다

왼쪽 클릭
CPU, GPU, 메모리, 온도, 저장 장치, 네트워크를 한눈에
오른쪽 클릭
캐릭터와 테마 고르기, 최대 FPS, 윈도우 시작 시 자동 실행
마우스 올리기
지금 사용률과 온도
